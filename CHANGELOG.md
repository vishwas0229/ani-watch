# Changelog

## 0.1.0

- Initial modular Ani-Watch architecture.
- Textual TUI with Home, Search, Anime Details, Episodes, History, Favorites, Library, and Settings surfaces.
- Conda-only project environment.
- AniList GraphQL metadata and OAuth synchronization foundation.
- PostgreSQL persistence with SQLAlchemy and Alembic.
- VLC/libVLC playback adapter and playback intelligence.
- Provider registry, fallback, health monitoring, and circuit breaking.
- Redis caching and network retry handling.
